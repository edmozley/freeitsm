## What this release is about

This release adds **Files**, a new module for the files your team has to hand out: installers too big to email, policies and contracts only some people should see, documents you need to know were actually read. It looks and works like a Windows desktop - icons, a taskbar, a start menu, and Explorer windows you can drag, resize and snap - so nobody needs to be shown how to use it. Nothing in it is visible to anybody until it has been shared with them, every file opens in the browser without being downloaded, and every action is recorded. Nothing breaks, and nothing changes for anyone until they open the new module.

## New features

- **Files, on a desktop.** Desktop icons (Documents, Recent, Search, Help, Settings), a taskbar with a live preview of each window when you hover over it, a start menu with your recent files and every other module, and windows that drag, resize from any edge, snap to the top or sides of the screen, minimise and maximise - and remember where you left them.
- **Explorer windows.** A folder tree beside the contents, icons or details view with sortable columns, a filter box in every window, right-click menus, cut, copy and paste, drag and drop (hold Ctrl to copy), rename in place and drag-to-select.
- **Upload anything, of any size.** Drag files in from your computer or use Upload. Files go up in pieces, so a multi-gigabyte installer is fine, with a Transfers window showing progress. A file with the same name can replace the old one as a new version - every version is kept, with a fingerprint (SHA-256) you can check a copy against - or be kept alongside it.
- **Open files without downloading them.** PDFs (shown by Mozilla's pdf.js), Word documents, spreadsheets, images, video, audio and text all open in a viewer window. **Zip files open like a folder**, and anything inside them - including another zip - opens in the same viewer.
- **Private until shared.** Permissions are set on folders, for people or teams, at five levels: View, Download, Upload, Modify and Full control. Folders take their parent's permissions unless you stop them, and a folder you have not been given access to simply does not exist for you - it does not appear anywhere, including in search. Administrators are not let in automatically; a folder nobody can reach can be recovered with **Take ownership** in **Files → Settings → Folders**, which is itself a permission and is recorded.
- **View only, and a watermark.** Someone with View but not Download can open a file but cannot download, copy out or print it. Any folder can switch on a **watermark** that stamps the viewer's name, the time and their IP address across everything opened from it - so a screenshot shows who took it. (Nothing a browser shows can be made impossible to photograph; this makes it traceable.)
- **Every action is recorded.** Opening a folder, viewing, downloading, uploading, renaming, moving, copying, deleting, permission changes and every refusal - with who, when, and from where.
- **Shortcuts.** Right-click a file or folder and create a shortcut to it beside the original, or on your own desktop. Drag files and folders onto the desktop to put shortcuts there, and drag shortcuts between folders and the desktop. A shortcut never gives anyone access the original does not.
- **Make it yours.** Each person picks their desktop colour, and whether the top navigation bar is always shown, appears when the mouse reaches the top of the screen, or is hidden (the start menu then carries everything it had).
- **Company logos.** Each company in **System → Companies** can have its own logo, shown in the corner of the Files desktop for the people who work in it. **System → Branding → Files desktop** decides whether a logo shows at all, and in which corner.
- **On a phone,** Files is a plain list of the same folders, and files open full screen.

## Upgrading

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification**. It adds the Files tables and a logo column for companies.
3. Hard-refresh your browser (Ctrl-F5).

Things worth knowing:

- **Who sees Files.** Analysts allowed every module get it straight away. Anyone on a restricted list needs it added in **System → Analysts** or **System → Teams**, like any other module.
- **Who can start.** Creating top-level folders, and Take ownership, is the **Folders** permission under Files in **System → Roles**. Administrators have it; give it to whoever should set up the folder structure.
- **Where the files go.** By default, `uploads/files/` inside FreeITSM, which the web server is told never to serve. **Files → Settings → Storage** can move it, ideally somewhere outside the web root. If you run Docker with **your own compose file**, add a volume for `/var/www/html/uploads/files` - the bundled `docker-compose.yml` already has one - or uploaded files will not survive a rebuild.

## Rollback

Safe - this release only adds to the database, so you can go back to 3.3.0. Files uploaded to the new module stay on disk, but 3.3.0 has no way to reach them.
