## What this release is about

Every PDF FreeITSM makes now prints Polish, Russian, Greek, Hindi, Tamil, Bengali and every other language FreeITSM ships correctly - until now they only managed Western European letters. Basic IMAP mailboxes, the username-and-password kind used by hosting providers, Fastmail and Zoho, no longer need anything installed on the server, so they work in the Docker image, on Windows and on Debian 13 for the first time. Each mailbox gets a **Test** button that sends you an email the way a reply would go, and Domains can now watch a name that answers differently inside your network than outside it.

## New features

- **PDFs in every language.** Knowledge articles, Report Packs, form submissions, Morning Checks, the Assets table, asset labels, changes, Network Mapper and Process Mapper diagrams and the organisation chart all print Polish, Russian, Greek, Hindi, Marathi, Bengali, Tamil, Telugu, Gujarati, Kannada, Malayalam, Punjabi and the rest correctly - including the scripts whose letters join together - and keep text inside the margins. The fonts are bundled, so it works on a server with no internet. Report Packs no longer turn non-Western letters into question marks. Chinese, Japanese and Korean are not covered yet. Reported by bbieganski.
- **Basic IMAP mailboxes with nothing to install.** A plain IMAP mailbox no longer needs PHP's `imap` extension, which PHP 8.4 dropped and current Debian cannot provide. It now works in the official Docker image, on Debian 13 and on Windows with PHP 8.4, with no DLL to find. Mail is read, attachments arrive with their real names (in any language), inline pictures come through, and folders with accented names work. Raised by Dr4inder and pappas81.
- **Test a mailbox's sending.** **Tickets → Settings → Mailboxes** has a **Test** button that sends a short email to you through the mailbox, the same way a reply goes. A Basic IMAP mailbox is tested with what is typed, before you save; Microsoft 365 and Google mailboxes as saved. When it fails it says which step and what to change.
- **Split DNS in Domains.** When a name answers differently inside your network - an internal server for staff, the public website for everyone else - open the public domain and choose **Add an internal view**. FreeITSM keeps a second, internal record of the same name, with its own health and owner, linked to the public one, and the internal one never sends the name outside your network.

## Improvements

- **Clearer mail errors.** When sending or reading mail fails, the message now says which step failed - the server never answered, STARTTLS refused, the sign-in was refused, the sender or a recipient was refused - instead of a code. A port and encryption that do not belong together (STARTTLS on 465, say) are named, with the fix.
- **A warning before replies fail.** A Basic IMAP mailbox whose port and encryption do not match gets a **!** warning on its row - before anybody tries to reply - and you can dismiss it if your provider does something unusual.
- **Better Knowledge PDFs.** An article's PDF now carries your organisation's own logo (**System → Branding**), or none if you have not set one - never FreeITSM's - and prints the article's tables as real tables instead of lines of text.

## Fixes

- **The cog on a Tickets dashboard widget did nothing**, and **New widget** and **Edit** in the Widget Library did not open either. They all work again. Reported by JITivT.
- **Clicking a folder while reading a Knowledge article left the article on screen** instead of showing the folder. Fixed by Dr4inder.
- **A ticket type rule with a Department condition never matched** tickets from the portal, email, messaging or web chat. It now does.
- **The Change Management risk matrix** cells sat out of line with their headings. Fixed by Dr4inder.

## Upgrading

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification**.
3. Hard-refresh your browser (Ctrl-F5) - this release updates the pages that make PDFs.

If you installed PHP's `imap` extension for FreeITSM, it is no longer used; you can leave it or remove it. If a Basic IMAP mailbox shows the new **!** warning about its port and encryption, open it, press **Test**, and change what the message says.

## Rollback

Safe - nothing was removed from the database (this release changes no tables), so you can go back to 4.10.0. Basic IMAP mailboxes would then need the `imap` extension again.
