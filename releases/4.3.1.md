## What this release is about

A same-day fix for 4.3.0. After upgrading, the Assets page showed a loading spinner and never listed anything. Nothing else changes, so it is a quick upgrade.

**Fixes a critical issue present in 4.3.0** - the Assets page never loaded ([#222](https://github.com/edmozley/freeitsm/issues/222)). If you are on 4.3.0, upgrade. Your asset data was never affected; only the page that shows it.

## Fixes

- **The Assets page never finished loading in 4.3.0.** It now lists your assets again. Thanks to @Abdullah31H, who found it and pinpointed the cause.

## Upgrading

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification**.
3. Hard-refresh your browser (Ctrl-F5) on the Assets page.

## Rollback

Safe - nothing was changed in the database, so you can go back to 4.3.0 with the code alone (but the Assets page will not load there).
