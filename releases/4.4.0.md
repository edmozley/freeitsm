## What this release is about

**Fixes a critical issue in 4.3.0: the Assets page never finished loading** ([#222](https://github.com/edmozley/freeitsm/issues/222)). If you are on 4.3.0, upgrade. Your asset data was never affected, only the page that shows it. So that this cannot slip through again, there is a new check, **Page health**, that opens every page in FreeITSM and confirms its scripts load, and the same check now runs on every change before a release. Pictures and PDFs on tickets also open in a window over the ticket instead of taking over the page.

## New features

- **Page health (System → Debug Tools → D019).** Press Run and it opens every page in FreeITSM and checks, in your browser, that each one's scripts can be read - the fault that left the Assets page stuck on its spinner. A row per module turns green or red as it goes, and any problem names the page, the line and the code around it, ready to copy into a bug report. **System → Database Verification** now shows when the pages were last checked, so after an upgrade you run both. The same check also runs automatically on every change to FreeITSM.
- **Pictures and PDFs open in a window over the ticket.** Click a picture or a PDF attached to a note, or one in a ticket's Attachments list, and it opens on top of the ticket in the same viewer as the Files module. Drag it, resize it from any edge, maximise it, zoom, download, and close it with × or Escape. Several can be open side by side, and on a phone it opens full screen. Requested by @Dr4inder ([#226](https://github.com/edmozley/freeitsm/issues/226)).

## Improvements

- **Pictures in the Files viewer refit as you resize the window**, as PDFs already did, until you zoom in or out yourself.

## Fixes

- **The Assets page never finished loading in 4.3.0** - it showed its spinner and listed nothing ([#222](https://github.com/edmozley/freeitsm/issues/222)). Thanks to @Abdullah31H, who found it and pinpointed the cause.
- **A picture on a ticket note could not be closed** - it replaced the whole Tickets page, Escape did nothing, and Back left the ticket ([#226](https://github.com/edmozley/freeitsm/issues/226)). Thanks to @Dr4inder.
- **The CMDB data-quality audit page asked for a file that does not exist** every time it opened. Found by Page health on its first run.

## Upgrading

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification**.
3. Hard-refresh your browser (Ctrl-F5). This release updates cached scripts on the Tickets, Files and Assets pages.
4. Then run **System → Debug Tools → D019 Page health** to confirm every page loads.

Things to know:

- The new screens are in English for now in other languages; translations follow.

## Rollback

Safe - nothing was changed in the database, so you can go back to 4.3.0 with the code alone (but the Assets page will not load there).
