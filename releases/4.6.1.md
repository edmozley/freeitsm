## What this release is about

A small release with one security fix, which is why it is out the day after 4.6.0. If you offer forms with lookup questions in the request catalogue, upgrade when you can. It also brings demo data for Starters & leavers and a few improvements to that module.

## Security

- **Lookup questions in the request catalogue are now fully checked on the server.** A signed-in portal user who tampered with their request could name a record that the question should not have offered: one from another company, or one from a lookup not open to customers. They could also change the name stored with their answer, so the request might mislead whoever read it. They could not read any data this way, and the fix needs nothing from you beyond upgrading. Present in every release from 1.0.0 to 4.6.0.

## Improvements

- **Starters & leavers demo data.** System → Demo data can now load templates, nine example cases and the New starter request form, so you can try the module before setting up your own.
- **The Starters & leavers case page uses the full width of the screen.**
- **The case list says "Waiting for answers"** instead of "No steps" for a case whose template asks a form's questions first.

## Fixes

- **Dates in a case's form answers read like the page's other dates**, on screen and when copied.
- **The answer box of a template's "Use this template when" rule no longer cuts off a long "is any of" list.**

## Upgrading

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification**.
3. Hard-refresh your browser (Ctrl-F5).

## Rollback

Safe - nothing was removed from the database, so you can go back to 4.6.0, though that brings the security issue back.
