## What this release is about

Most of this release is Network Mapper. It now has shapes, icon libraries, pictures, pages and layers, multi-select, lines that join anything to anything, right-click menus and links to Knowledge articles, so a network diagram no longer has to be redrawn somewhere else to look finished. Around it are a handful of things people asked for: workflows that run in an order you choose, licences that can be perpetual, Morning Checks in Report Packs, renamable change fields, and Starters & leavers cases that HR can follow on the portal. It also fixes brand-new installs, which have been stopping partway through since 5.8.0.

> **Fixes a critical issue present in 5.8.0 to 5.10.1 for new installs.** A brand-new install from `database/freeitsm.sql` - which includes the Docker quickstart - stopped partway through creating the database, so it had no administrator account and could not be signed in to. Existing installs that upgraded were not affected. If you set up a new install on one of those versions and could not sign in, start it again on 5.11.0.

## New features

- **Network Mapper: shapes.** A Shapes tab beside the CMDB classes with 61 shapes - basic, flowchart, arrows, zones and containers, text and notes. Drag them on, resize, rotate, type in them, and style them with fill, gradient, border, shadow, rounded corners and font, or pick one of ten quick styles.
- **Network Mapper: icon libraries.** Libraries on the Shapes tab browses the icons.diagrams.net catalogue (about a thousand sets, vendors included), shows each set's licence and author, and imports the ones you want into your install.
- **Network Mapper: your own pictures.** Upload a PNG, JPEG, GIF or WebP to My images, or paste a screenshot straight onto the diagram with Ctrl+V. A picture belongs to whoever added it; only they or an administrator can remove it.
- **Network Mapper: pages and layers.** Tabs under the diagram for separate pages, and per page a Layers panel to show, hide, lock and reorder what is drawn.
- **Network Mapper: select several things at once.** Shift or Ctrl+click, or drag a box. Move, nudge, align, space out, group and delete them together.
- **Network Mapper: lines between anything.** A line can join two shapes, a shape and a device, or two devices, and follows both ends. Each line has a label, colour, width, solid / dashed / dotted, an arrowhead of your choice at either end, and a straight, elbow or curved route.
- **Network Mapper: right-click menus** on shapes, devices, lines and empty space, with cut, copy, paste, duplicate, arrange, layer and style.
- **Network Mapper: devices look how you want.** A device can have its own colour, its box can be resized so a long name fits, and it takes the same styling as shapes. A CMDB class can be given an icon in CMDB → Settings → Classes, used by every device of that class.
- **Network Mapper: Knowledge articles on diagrams.** Link an article to a device, a shape or the whole diagram; a small book opens it, and the article lists the diagrams that use it. People only ever see articles they are allowed to read.
- **Workflows run in an order you set.** Workflows → Run order lets you drag the workflows on one trigger into order, and a new **Stop here when this one runs** tick skips the ones after it when its conditions match.
- **Perpetual licences.** A licence now says how it is counted (per user, per device, site, concurrent) and, separately, its term: Subscription, Perpetual (nothing to renew) or Perpetual with maintenance. Licences already typed as Subscription or Perpetual are moved across for you.
- **Morning Checks in Report Packs.** Three new blocks for a week or a month: a summary per check, the exceptions with their notes, and a chart by status. Only the days each check was due count.
- **Rename a change form field.** Changes → Settings → Fields - for example call Description "Implementation Plan". The new name shows on the form, the detail view, the PDF, the lists and the history.
- **HR can follow Starters & leavers cases on the portal.** System → Self-service portal → Starters & leavers cases gives members of chosen People groups a read-only page of their own company's cases, with how many steps are done and who owns each one. It is off until you switch it on, and never shows notes, kit or history.
- **A leaver who is not in Users can still have a case.** New case offers Not in Users for leavers and movers, as it already did for starters.
- **Try a new sign-in provider with a few analysts.** On a provider's Signing in tab, **Show the button on the analyst login** can be unticked. The analysts assigned to it still reach it by typing their email; everyone else sees the login page as before.
- **The Files viewer steps through several files.** Previous / next and the arrow keys move through the folder, several selected files open in one viewer or a window each, and a Slideshow plays the pictures.

## Improvements

- **Network Mapper fits a laptop screen.** The title has its own row, Save and the version buttons sit beside it, and the toolbar no longer pushes Save off the edge. PNG and PDF exports can be downloaded or saved straight into Files.
- **The Watchtower browser extension asks for less.** Version 1.1.0 only asks for access to your own FreeITSM server, when you save its settings, instead of every website at install.

## Fixes

- **Network Mapper:** an edit made while a slow save was still going could be lost even though it said Saved; exports drew a plain arrow on every line whatever its style; Database Verification could delete lines that end on a shape; My images refused pictures over 512 KB; a linked draft or archived article showed as one you could not open.
- **Editing a CMDB class wiped its icon.**
- **An asset's Last seen did not follow Intune.** It stayed at the day of the first sync, so Intune-only machines showed as not seen on Watchtower.
- **Security → Trusted Device → Trust duration only applied to new devices.** Shortening it, or setting it to 0, now applies to devices that are already trusted too.
- **Save to Files for an export** accepted files that were not really spreadsheets or CSVs.
- **Photo Album:** the EGA and CGA looks turned webcam pictures grey; with Dithering on they now show in colour.
- **The REST API** now returns everything a network diagram is drawn with, and its documentation describes the CMDB impact fields fully.

## Upgrading

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification**.
3. Hard-refresh your browser (Ctrl-F5) - this release updates cached JavaScript.

## Rollback

Safe - this release only adds to the database, so you can go back to 5.10.1.
