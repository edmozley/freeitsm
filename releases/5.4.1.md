## What this release is about

A small release of fixes, all from bug reports - thank you to everyone who sent them. The one most likely to have hit you: if your analysts saw an empty inbox after upgrading, FreeITSM now tells administrators, on every page, when **Database Verification** still needs running after an update.

## Improvements

- **A reminder to run Database Verification after an update.** An update replaces FreeITSM's files, but the database only catches up when an administrator runs **System → Database Verification**. Until then, pages that read something new can fail. Every administrator now sees a notice at the bottom of each page when that is the case, with **Verify** to go straight there; it goes away after the next clean run. Anyone else who hits such a page is told to ask an administrator, instead of seeing a database error. Your first page after this update shows the notice too - run Database Verification once and it is gone.

## Fixes

- **Analysts in a team saw an empty inbox after an upgrade**, with an error about a missing `ticket_watchers` table, while administrators saw every ticket. The database had not been brought up to date; running Database Verification fixes it, and the reminder above now prevents it ([#369](https://github.com/edmozley/freeitsm/issues/369)).
- **The bell showed only a name when a ticket was handed to your team** - which looked like the wrong person handling the ticket. It now reads *Handed to your team by ...*, and its switch in **Preferences → Notifications** has a proper label instead of a code ([#362](https://github.com/edmozley/freeitsm/issues/362), [#365](https://github.com/edmozley/freeitsm/issues/365)).
- **In workspace mode, a link inside a task opened the whole of FreeITSM inside the ticket.** Links in a task on the **Work** tab now open in a new browser tab, and the task stays open in the ticket ([#360](https://github.com/edmozley/freeitsm/issues/360)).
- **The LMS demo data would not import**, stopping on a duplicate record. It now imports, and the demo course progress shows against the right people ([#366](https://github.com/edmozley/freeitsm/issues/366)).

## Upgrading

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification**.
3. Hard-refresh your browser (Ctrl-F5).

## Rollback

Safe - nothing was removed from the database, so you can go back to 5.4.0.
