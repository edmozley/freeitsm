## What this release is about

A small release: one new screen, and four fixes for things you reported after 5.5.0. **System → Storage usage** shows every folder FreeITSM keeps files in, how many files are in each and how much space they take - useful for backups, and for knowing where your disk went. If you use Projects, upgrade: 5.5.0 broke **Add someone** on a project, and this puts it right.

## New features

- **System → Storage usage.** One list of every folder FreeITSM keeps files in - ticket and change attachments, documents, Files, learning content, recordings, logos, the encryption key and the rest - with where it is on the server, how many files it holds, how much space they take and when the newest one arrived. A total and the free space left on the drive sit underneath. In Docker it also says whether each folder survives an update, so you can see before updating if anything would be lost. It only looks: nothing on the page moves or deletes anything.

## Fixes

- **Add someone on a project did nothing** in 5.5.0, and **income lines on a project's Budget tab never saved** - saving a deliverable could also send an empty income save. Both work again ([#392](https://github.com/edmozley/freeitsm/issues/392), thanks @acelr22).
- **The Knowledge image dialog can now take a picture from your computer.** It has an **Upload** tab - browse for a picture or drop one on it. Large photos are scaled down first so articles stay a sensible size ([#391](https://github.com/edmozley/freeitsm/issues/391), thanks @acelr22).
- **A project created before you changed the install's currency was stuck in the old one.** Its Budget tab now offers **Use {currency}** to bring it onto the current one - a relabel, amounts are not converted ([#386](https://github.com/edmozley/freeitsm/issues/386), reported and fixed by @cloudcogsio).
- **The header ran off the right edge on laptop screens** once a second company existed, hiding the bell and your account menu. The buttons now tighten, and if needed become icons, so everything fits ([#393](https://github.com/edmozley/freeitsm/issues/393), reported and fixed by @cloudcogsio).

## Upgrading

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification**.
3. Hard-refresh your browser (Ctrl-F5).

## Rollback

Safe - nothing was added to or removed from the database, so you can go back to 5.5.0.
