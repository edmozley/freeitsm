## What this release is about

The **war room** now does what people expect of a team chat: right-click a message to react, quote it, pin it, save it, reply in a thread, forward it or see who has read it, share a file from Files as a live card - and, with an AI provider set up, everyone reads the conversation in their own language. **Forms** can now raise a ticket **for the person picked** on the form, so the service desk can log a request on someone's behalf, and Forms help has a new **Recipes** section that walks through whole jobs start to finish. **Fourteen more languages are now complete**, so FreeITSM is fully translated into 22 languages besides English.

## New features

- **The war room: right-click a message.** React with an emoji (ten favourites, and a picker for the rest), reply with a quote, copy the message or a permanent link to it, pin it, save it for yourself, mark it as unread, **reply in a thread**, **forward** it to another conversation or a person, and see **who has read it**. Files in messages open in the same viewer as everywhere else, and the pinned bar shows the newest pin rather than just a count.
- **Share a file from Files in the war room.** The **+** offers your computer or Files; a file from Files appears as a live card that respects the file's own sharing settings.
- **Everyone reads the war room in their own language.** Type in yours; with an AI provider set up under the war room's **AI** settings, each person sees messages in theirs, with the original a click away. Translations are kept, so each message is translated once per language.
- **Raise a ticket on behalf of someone.** A form's **Raise a ticket** step has a new **Requester is the person picked in** choice: pick a *Who is this for?* question and the ticket is raised for that person, whoever filled the form in. The picked record's details can also be used in workflows and messages - their email, department, job title and more ([#420](https://github.com/edmozley/freeitsm/issues/420), thanks @pappas81).
- **Recipes in Forms help.** Worked examples of whole jobs: who a raised ticket is for, raising a ticket for whoever sends a form, on behalf of someone else, after approval, and sending the answers to another system.
- **Knowledge: choose the largest picture the REST API accepts**, under **Knowledge → Settings → Images**, and API clients can ask what it is before uploading. The Knowledge migration scripts now check every picture against it before writing anything ([#417](https://github.com/edmozley/freeitsm/issues/417), thanks @Dr4inder).
- **Eleven new API scripts** in **System → API → Scripts**, each in PowerShell and Python, that combine several modules - a Monday morning briefing, and more. All use placeholder keys; nothing is filled in for you.

## Improvements

- **Fourteen more languages are complete:** Italian, Dutch, Brazilian Portuguese, Russian, Norwegian Bokmål, Norwegian Nynorsk, Afrikaans, Malay, Bengali, Gujarati, Hindi, Malayalam, Marathi and Tamil - every screen, including Case reports, the Help assistant and Starters & leavers. A few help lines that showed raw codes in 17 languages are fixed too.
- **One company editor, everywhere.** **+ New company...** in the person editor now opens the full company form - name, ticket code, outside reference, tax ID and custom fields - instead of a name box. It suggests the company from the person's email address, can route that domain's mail to the company, and warns before you create a duplicate. **People → Companies** gains **New**, and each company's page gains **Edit** ([#419](https://github.com/edmozley/freeitsm/issues/419), thanks @pappas81).
- **The form editor warns when a ticket has nobody to be raised for.** A **Raise a ticket** step that cannot know who the ticket is for when staff fill the form in now says so in the editor, instead of the ticket quietly not being raised.
- **War room personal choices** - desktop alerts for mentions, reading in your own language, how mentions look - moved to **Preferences → War room**, each with an explanation. The war room's **Situation report** settings tab is now **AI**.

## Fixes

- **A form's "pick a ..." answer reached workflows as "2, User Test"** - a record number and a name stuck together - so it could not be used for anything. It now reads as the name ([#420](https://github.com/edmozley/freeitsm/issues/420), thanks @pappas81).
- **Settings on one page showed sections in a different order from the tabs**, so the index down the side did not match the page ([#418](https://github.com/edmozley/freeitsm/issues/418), thanks @pappas81).
- **AI features failed with the newest Claude models.**
- **The war room could fail to open after upgrading**, until Database Verification had been run.
- **The ticket list preview showed quote marks and ampersands as `&quot;` and `&amp;`.**

## Upgrading

1. Pull the new code, or rebuild the Docker image.
2. Sign in as an administrator and run **System → Database Verification**. It adds the war room's reactions, pins, saved messages, read marks, translations and file links.
3. Hard-refresh your browser (Ctrl-F5) - this release updates cached JavaScript.

Rollback: safe - this release only adds to the database.
